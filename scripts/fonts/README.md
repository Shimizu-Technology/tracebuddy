These Google Fonts files are inputs for `npm run glyphs:generate`. Keeping them here lets `npm run glyphs:check` run offline. The mobile app bundles the generated SVG paths. The SIL Open Font License for each font is in `mobile/src/data/font-licenses/`.

- [Fredoka](https://github.com/google/fonts/tree/a60a77e14f28abd4ef243a1b5dfc48df0cec5205/ofl/fredoka) uses the original variable font at weight 700 and width 100.
- [Andika](https://github.com/google/fonts/tree/fffdadf0f0c9cc1ec8b407063424a8bfbee05611/ofl/andika) uses the original Bold font.
